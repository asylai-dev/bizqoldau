# BizQoldau MVP

**BizQoldau** — каталог-навигатор по мерам поддержки предпринимателей Казахстана (гранты, субсидии, льготные кредиты, налоговые льготы).
Сайт помогает найти подходящую программу и перейти на официальный сайт оператора. BizQoldau **не принимает заявки** и не является государственным органом.

Это обычный сайт на React + Vite. Бэкенда и базы данных нет: все программы лежат в одном файле внутри проекта.
Сайт работает на русском и казахском языках (переключатель RU / ҚАЗ справа вверху).

## Что нужно установить (один раз)

1. Откройте https://nodejs.org и скачайте версию **LTS** (подойдёт Node.js 20 или новее). Установите как обычную программу.
2. Проверьте в Терминале (Mac: Cmd + Пробел, напишите «Терминал»):

```bash
node -v
npm -v
```

Обе команды должны показать номер версии.

## Как запустить

Откройте Терминал и перейдите в папку проекта (подставьте свой путь):

```bash
cd ~/Downloads/bizqoldau
npm install
npm run dev
```

`npm install` скачивает нужные библиотеки (нужен интернет, делается один раз).
`npm run dev` запускает сайт.

## Как открыть

В Терминале появится адрес:

```
http://localhost:5173
```

Откройте его в браузере. Остановить сайт: в Терминале нажмите `Ctrl + C`.

## Как проверить, что всё работает

1. На главной выберите **Алматы → Сельское хозяйство → Льготный кредит** и нажмите «Найти программы» — должна остаться одна программа («Ауыл аманаты»).
2. В поиске введите `кофейня` — появятся программы, где это слово есть в данных.
3. Нажмите «Подробнее →» и пролистайте страницу.
4. Нажмите «Перейти на официальный сайт →» (есть не у всех программ — см. ниже).
5. Нажмите «Сбросить фильтры» — вернутся все программы.
6. Введите `абракадабра` — появится «😔 Ничего не нашли».

## Где находятся данные

Файл: **`src/data/programs.js`**. Это список программ, перенесённый из листа «Программы» файла `bizqoldau.xlsx`
(копия Excel лежит в папке `data-source/`). Казахские названия регионов, сфер и типов — в `src/data/labels.js`.

На сайте видны только программы со статусом `"Опубликовано"`. Программы со статусами «Анонс», «Черновик», «Закрыто» скрыты.

## Как добавить новую программу

Откройте `src/data/programs.js`, скопируйте любой блок `{ ... }`, вставьте в конец списка (перед `]`), поставьте уникальный `id` и поменяйте значения:

```js
{
  id: 9,
  name: "Название программы",
  operator: "Кто проводит программу",
  type: "Грант",                 // Грант, Субсидия ставки, Льготный кредит, Гарантия, Налоговая льгота, Обучение
  region: ["Алматы"],            // или ["Вся РК"]
  sphere: ["Сельское хозяйство"],// или ["Все сферы"]
  conditions: "Короткие условия",
  amount: "до 1 000 000 ₸",
  deadline: "",                  // пусто или "2026-12-31"
  source: "https://...",
  status: "Опубликовано",
  verified: "2026-10-04",        // дата последней проверки
  keywords: ["кофейня", "кафе"],
  shortDescription: "Одно-два предложения для карточки",
  suitableFor: ["ИП", "ТОО"],
  fullDescription: "Подробное описание",
  requirements: ["Требование 1", "Требование 2"],
  documents: ["Документ 1", "Документ 2"],
  howToGet: ["Шаг 1", "Шаг 2"],
  officialWebsite: "https://сайт-оператора.kz",
  officialWebsiteVerified: true, // true — только если вы сами проверили, что это официальный сайт оператора
  kk: {}                         // казахская версия (можно оставить пустой — покажется русский текст)
}
```

Новая сфера или тип автоматически появятся в фильтрах. Для казахского названия добавьте их в `src/data/labels.js`.

## Важно про официальные ссылки

Кнопка «Перейти на официальный сайт →» показывается **только** если `officialWebsiteVerified: true`.
Иначе пользователь видит «Официальная ссылка требует проверки.» Не ставьте `true`, пока не убедились, что ссылка ведёт на сайт оператора.

## Как выложить в интернет

```bash
npm run build
```

Появится папка `dist/` — это готовый сайт. Загрузите её содержимое на любой статический хостинг (Netlify, Vercel, GitHub Pages, Cloudflare Pages)
и подключите свой домен в настройках хостинга. Адреса страниц вида `#/programs` работают без дополнительной настройки сервера.
Для проверки сборки локально: `npm run preview`.
(Открывать `dist/index.html` двойным кликом нельзя — браузер блокирует такие скрипты. Используйте `npm run preview` или хостинг.)

## Структура проекта

```
bizqoldau/
├── package.json, vite.config.js, index.html, README.md
├── data-source/bizqoldau.xlsx      исходный Excel
└── src/
    ├── main.jsx, App.jsx           запуск и простой роутер
    ├── i18n.js                     тексты RU/KK
    ├── data/programs.js, labels.js данные
    ├── lib/programs.js             фильтры, поиск, сортировка
    ├── components/                 Header, Filters, SearchBar, QuickFilters, ProgramCard, Footer
    ├── pages/                      Home, Programs, ProgramDetails, About
    └── styles/styles.css
```

## Ограничения MVP

- Данные обновляются вручную (редактированием `programs.js`).
- Нет входа, оплаты, админ-панели, подписок и бэкенда — так задумано для первой версии.
- Условия программ собраны из открытых источников и могут устареть. Проверяйте у оператора.
- Казахские тексты нужно показать носителю языка перед публичным запуском.
